# نظام محاسبة وإدارة وكالات الدعاية والإعلان والمطبوعات (الإصدار الاحترافي المطور v2.0)

نظام محاسبي وتشغيلي متكامل مبني بـ **React 19 + TypeScript + TailwindCSS 4 + Vite** ومصمم خصيصاً لوكالات الدعاية والإعلان والمطابع الرقمية ومعامل اللوحات والليزر.

---

## أبرز المميزات والإصلاحات الجوهرية في هذا الإصدار

1. **تسوية ثنائية الاتجاه بين السندات والفواتير والمشتريات**:
   - عند إنشاء أو تعديل أو حذف أي سند قبض أو سند صرف مرتبط بفاتورة مبيعات أو فاتورة مشتريات، يُعاد احتساب الرصيد المدفوع والمتبقي وحالة الفاتورة تلقائياً في اللحظة نفسها دون أي تضارب في الخزينة.
2. **ترقيم تسلسلي ذري موحد وغير قابل للتكرار**:
   - أرقام الفواتير (`INV-YYYY-XXXX`) وعروض الأسعار (`QT-YYYY-XXXX`) والسندات (`RC` / `PV`) وإشعارات الدائن (`CN`) ومرتجعات المشتريات (`PR`) تُحفظ في عداد ذري مستقل لا يتكرر أبداً حتى بعد حذف أي مستند.
3. **تحويل عروض الأسعار مع الحفاظ الكامل على الضريبة والخصم**:
   - اعتماد عرض السعر وتحويله إلى فاتورة مبيعات ينقل حالة الضريبة ونسبتها وقيمتها والخصومات بدقة محاسبية كاملة.
4. **نظام المرتجعات وإشعارات الدائن الضريبية والهالك الطباعي**:
   - إصدار إشعارات دائن ضريبية لمرتجعات المبيعات (كامل / جزئي / استبدال / تالف طباعة) ومرتجعات المشتريات للموردين مع منع تجاوز الكميات المباعة، وإرجاع الخامات للمخزون، وإصدار سندات الاسترداد تلقائياً، وطباعة الإشعار مع كود QR والتفقيط العربي.
   - سجل خاص لتسجيل **الهالك والتالف التشغيلي** أثناء الطباعة والقص واحتساب تكلفته في صافي الربح.
5. **ربط المخزون الآلي بدفتر حركات المستودع**:
   - توريد تلقائي للخامات عند الشراء، وصرف تلقائي عند البيع، وإرجاع/خصم عند المرتجعات، مع سجل حركات مخزون مفصل (`Inventory Movements Ledger`).
6. **نظام الموارد البشرية والحضور والانصراف ومسيرات الرواتب (HR & Payroll)**:
   - سجل متكامل للموظفين والفنيين (مصممين، فنيي طباعة، فنيي تركيب) مع الرواتب الأساسية والبدلات والآيبان.
   - دفتر حضور وانصراف يومي يحسب أيام الغياب ودقائق التأخير والساعات الإضافية (Overtime 1.5x).
   - مسير رواتب شهري يخصم الغياب والتأخير تلقائياً، وعند اعتماده وصرفه يولّد **قيد مصروف رواتب + سندات صرف مالية** لكل موظف تلقائياً.
7. **تأمين القواعد والبيانات وسجل التدقيق المشفر**:
   - قواعد `firestore.rules` محمية ومقصورة على فريق الوكالة المصرح لهم.
   - حفظ رموز الجلسة في `sessionStorage` بدلاً من `localStorage` للحماية من XSS.
   - سجل تدقيق بسلسلة تجزئة مترابطة (`Hash Chain`) لكشف أي تلاعب، مع أدوات التصدير والاستعادة بصيغة `JSON` و`Excel (.xlsx)`، وزر تصفير البيانات التجريبية من الإعدادات.

## طريقة تشغيل المشروع على جهازك

### المتطلبات الأساسية
- تثبيت **Node.js** (الإصدار 18 أو أحدث) من الموقع الرسمي: [https://nodejs.org](https://nodejs.org)

### خطوات التشغيل السريعة

1. **فك ضغط ملف المشروع** في مجلد على جهازك، ثم افتح موجه الأوامر (`Terminal` أو `CMD` أو `PowerShell`) داخل المجلد:
   ```bash
   cd ad-agency-accounting-pro
   ```

2. **تثبيت المكتبات البرمجية** (تُنفذ مرة واحدة فقط عند أول تشغيل):
   ```bash
   npm install
   ```

3. **تشغيل النظام في وضع التطوير المحلي**:
   ```bash
   npm run dev
   ```
   سيعمل النظام مباشرة على الرابط:
   `http://localhost:3000`

4. **لبناء نسخة الإنتاج النهائية (Production Build)**:
   ```bash
   npm run build
   ```
   ولمعاينة نسخة الإنتاج:
   ```bash
   npm run preview
   ```
